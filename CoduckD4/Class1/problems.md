# Problems


- ### Queuing to get water

There are $$\displaystyle n$$ people queuing up to get water from a tap. 

If each person takes $$\displaystyle T_i$$ time to get water, please write a program to find the order in which these $$n$$ people queue up (if there are multiple orders, 

the one with the smaller number comes first) so that the average time spent by the $$n$$ people is minimized.
